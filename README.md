# Arena das Esferas

**Alpha 0.3 — Entrada na Arena** · jogo de fantasia arcana para navegador.

## Como jogar
1. No pátio, toque no portão ou em **Entrar na arena**.
2. Aguarde o sorteio de três esferas.
3. Escolha sua esfera.
4. A batalha começa automaticamente. Após o resultado, prossiga ao próximo duelo.

**Esferas disponíveis:** Lâmina, Veloz, Titã, Bastião e Voltagem (que ativa raios ao ricochetear nas paredes).

O jogo completo está no arquivo [index.html](./index.html), com CSS e JavaScript no mesmo arquivo, sem dependências externas.

## Publicar no GitHub Pages
1. Se sua conta GitHub é Free, o repositório precisa estar **público** (Settings → General → Danger Zone → Change repository visibility).
2. Em **Settings → Pages**, escolha **Deploy from a branch**.
3. Selecione `main` e `/(root)`, e clique em **Save**.
4. O endereço esperado depois de o GitHub publicar será `https://fideonline.github.io/-arena-das-esferas/`.

**Importante:** o nome do repositório começa com um hífen (`-arena-das-esferas`); ele faz parte da URL.

## Direção de desenvolvimento
O projeto prioriza a sensação de um jogo (entrar na arena → sortear → escolher → lutar), arena compacta, habilidades com ricochetes, ampla variedade de esferas e visual de fantasia arcana. Não misturar com NOXFENDA ou outros jogos.
